두 눈의 위치와 각 눈의 시선 방향을 3D로 추정하면, 사용자가 보는 점은 이론적으로 두 시선 직선의 **교점**입니다. 하지만 추정에는 노이즈가 있어서 3D 공간의 두 직선은 거의 항상 **꼬인 위치**(만나지도 평행하지도 않음)에 있습니다. 그래서 실제로는 "두 직선이 가장 가까워지는 두 점"을 구하고 그 중점을 쓰게 됩니다. 정확히 만나는 경우는 이 계산에서 거리가 0인 특수한 경우일 뿐이라, 한 가지 식으로 둘 다 처리할 수 있습니다.

## 설정

```text
P_a, P_b : 왼쪽·오른쪽 눈 위치
V_a, V_b : 왼쪽·오른쪽 시선 방향
C_a = P_a + t·V_a   (왼쪽 직선 위의 점)
C_b = P_b + s·V_b   (오른쪽 직선 위의 점)
```

## 가장 가까운 두 점의 조건

두 점 사이 벡터 `C_a − C_b`가 가장 짧아지는 때는, 이 벡터가 **두 직선 모두에 수직**일 때입니다.

```text
(C_a − C_b) · V_a = 0
(C_a − C_b) · V_b = 0
```

`w = P_a − P_b`로 두고 대입해 정리하면 t, s에 대한 2×2 연립방정식이 됩니다.

```text
a = V_a·V_a,  b = V_a·V_b,  c = V_b·V_b
d = V_a·w,    e = V_b·w

a·t − b·s = −d
b·t − c·s = −e
```

## 닫힌 식

```text
den = a·c − b²
t = (b·e − c·d) / den
s = (a·e − b·d) / den
```

그다음 `C_a`, `C_b`를 계산하고, 보는 점은 중점 `(C_a + C_b) / 2`로 둡니다. 두 점 사이 거리 `|C_a − C_b|`는 그대로 **품질 지표**로 쓸 수 있습니다. 두 시선이 많이 어긋나 있으면 추정이 불안정하다는 신호입니다.

```python
import numpy as np

def closest_points(Pa, Va, Pb, Vb, eps=1e-9):
    w = Pa - Pb
    a, b, c = Va @ Va, Va @ Vb, Vb @ Vb
    d, e = Va @ w, Vb @ w
    den = a * c - b * b
    if den < eps * a * c:            # 거의 평행
        t, s = 0.0, e / c             # 한 점을 고정하고 다른 직선에 투영
    else:
        t = (b * e - c * d) / den
        s = (a * e - b * d) / den
    Ca, Cb = Pa + t * Va, Pb + s * Vb
    return (Ca + Cb) / 2, np.linalg.norm(Ca - Cb), t, s
```

## 놓치기 쉬운 것

- **평행일 때.** `den = a·c − b²`은 두 방향이 평행하면 0이 됩니다(코시–슈바르츠 부등식에서 등호). 먼 곳을 볼 때 두 시선은 거의 평행해지므로 이 경우가 실제로 자주 나옵니다. 상대 임계값으로 감지하고 대체 규칙을 둡니다
- **t, s의 부호.** 직선이 아니라 눈에서 나가는 **반직선**이라면 t, s가 음수인 해는 눈 뒤쪽의 점입니다. 음수면 0으로 자르거나, 단일 눈 시선과 화면 평면의 교점으로 대체합니다
- **"교점이 있을 때"를 따로 풀지 않는다.** `P_a + t·V_a = P_b + s·V_b`를 3×2 행렬의 역행렬로 풀려고 하면 정사각 행렬이 아니라 역행렬이 없습니다. 위의 수직 조건은 그 방정식의 최소제곱해와 같아서, 교점이 있으면 거리 0인 해를 그대로 돌려줍니다
- **좌표계를 맞춘다.** 눈 위치와 시선 방향이 같은 좌표계(카메라 또는 얼굴 기준)인지 먼저 확인합니다. 섞여 있으면 식이 맞아도 결과가 틀립니다

## 정리

- 3D의 두 직선은 노이즈 때문에 거의 항상 만나지 않는다. 가장 가까운 두 점의 중점을 쓴다
- 수직 조건 두 개 → 2×2 연립방정식 → 닫힌 식
- 평행(분모 0), 반직선 부호, 좌표계 세 가지를 처리한다. 두 점 사이 거리는 품질 지표로 쓴다
