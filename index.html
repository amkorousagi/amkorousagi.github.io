2024.01 – 현재
  • 사내 시선 추적 SDK — 추론을 C++ 네이티브 코어(ONNX Runtime·TFLite)로 옮기고 C API로 감싸 React Native·Unity에 같은 API로 제공. 렌더링과 분리된 전용 스레드로 게임 부하에서 추론 1회 처리 시간 Galaxy Tab S7 42.4 → 15.1ms(화면 47 → 60fps), iPad M1 12.5 → 7.4ms (DEV/QA 배포)
  • 추론 최적화 — 실기기 계측으로 병목이 연산량이 아닌 GPU→CPU 결과 전달임을 찾아 구조를 바꿔 시선 파이프라인 추론 시간 120–300ms → 42–48ms. 모델 그래프 정리(레이아웃 통일·양눈 배치 추론·출력 병합)로 추론 시간 2~4배 단축, 모델 크기 -40%
  • 출력이 같은 런타임 최적화 — 연산자별 프로파일로 활성화 연산 병목을 찾아 그래프 정리만으로 랜드마크 추론 24% 단축(출력 비트 동일), TFLite·XNNPACK 하이브리드, 전처리 14.6 → 6.3ms. 정확도가 바뀌는 FP16·INT8은 기각
  • 모델 재설계 — 거리 추정 기준을 얼굴 크기에서 홍채 직경 + 카메라 초점거리로 바꿔 최대 오차 ±10cm → 1.1–2.5cm
  • 데이터·평가 — 성인 16명 × 기기 2종 실데이터로 판정 모델 4종을 피험자 단위 교차검증으로 재적합
  • CI/CD·품질 게이트 — Jenkins로 Google Play 업로드까지 자동 배포, LLM 자동 PR 리뷰봇, 시선 회귀 테스트 49/49 CI 게이트, SDK npm 자동 배포
